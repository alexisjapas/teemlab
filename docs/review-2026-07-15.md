# UI review — 2026-07-15 (post-0.6.2, comp alignment round 2)

Working notes from the second comp review (`docs/ui-mockups/teemlab.dc.html`).
The 0.6.3 patch closes the items marked ✔; the rest are recorded here so they
are not lost.

## Open questions (parked on purpose)

- **Per-gene means (Observe, left panel).** Kept, but pinned at the very bottom
  of the panel, folded. Revisit whether it earns its place at all — the gene
  drift curves in the bottom strip may already answer the same question
  (Rule 12: does it help understand why an ecosystem holds?).
- **Trophic graph overlay (Observe).** The overlay reads poorly over the live
  arena (contrast, occlusion with moving agents). Candidate alternatives: render
  it in a side-panel card instead of over the sim (the Studio food-web panel
  already draws the same `TrophicGraph`), or dim the arena while the overlay is
  up. To be decided before Analyze lands.

## Fixed in 0.6.3 ✔

- Gauges: comp-style slim rounded bars (`theme::gauge` / `gauge_sized` +
  `caption_value`) replace `egui::ProgressBar` in the inspector (energy,
  nutrient, throttle, perception rays).
- Observe top strip: the scenario menu chip carries the document name + dirty
  marker (no repeated file name, no screen title); Record replaces Export video
  (export is one of the Record menu's options).
- Observe left panel: Live stats → Layers → Trophic toggle → Per-gene means
  (bottom, folded).
- Observe right panel: plain "Agent inspector" header (no CollapsingHeader);
  Capture-to-scenario chip right under the title; Identity as the comp's 2×2
  mono mini-cards; captions instead of bold headers throughout.
- Curves: the two plots side by side across the full strip width, caption +
  legend each (the gene plot's legend was drawn but starved of width by the
  stacked layout); bottom panel default 190 pt (comp's 150 px strip + header).
- Library: gallery on the `--bg` tone; cards laid out top-down (the wrapped
  layout was flowing thumbnail and body side by side — the actual cause of the
  overlaps); 16 px grid gap; meta line truncates instead of wrapping.
- Studio top strip: name/dirty deduplicated (menu chip only).
- Lab: mode selector as the comp's segmented control; INNER·BREED dot in amber;
  the three metric tiles on equal thirds; scenario name in mono.

## Still diverging (next rounds)

- **Studio (largest gap).** The comp specs, per zone:
  - World panel (264 px): caption blocks (ARENA / SOURCES & ROCKS / COMPONENTS /
    …) with card rows, not CollapsingHeaders; slim accent slider for
    half-arena; seed as a mono chip; "Place in arena" as a dashed drop button;
    per-component card rows (dot + name + mono decay).
  - Cast (184 px, on `--bg`): card rows — color dot, name over sub-label, mono
    count right, accent hairline on the selected row; "+" icon button beside
    the "Cast" title.
  - Detail (on `--bg`, max-width 560): species header (dot + name + warning
    pill); BODY as a 2-col grid of labelled 38 px card fields; GENES as
    collapsible card groups with slim accent sliders (150 px label · slider ·
    52 px mono value); NUTRITIONAL PROFILE as side-by-side cards; BRAIN as a
    card row with a raised select; FOOD WEB as a card with the graph beside
    per-chain status pills.
  - Header: explicit "Overwrite" (card) + "Save as new" (teal) buttons.
- **Lab results header.** Comp: a 56 px strip over the results zone — teal Run
  button, slim progress gauge + "gen 15 / 24" mono read-out, cores/speed at the
  right. The breeding dashboard's transport should migrate there.
- **Elite genomes / leaderboard.** Comp: bordered surface card, header row +
  hairline-separated rows (rank · dot · name · gen · fitness · save action).
- **Library tabs.** Comp: underline tabs (2 px accent border-bottom) +
  mono-count suffix, and the examples/saved switch as a card-filled segmented
  control; current `selectable_label`s approximate them.
- **Arena overlays (Observe).** Comp: run-time + paused chips floating over the
  arena top, follow selector bottom-left, zoom cluster bottom-right — currently
  in panels.
- **Editor sliders.** Comp: 6 px accent track with a ringed knob; egui's
  default slider everywhere in Studio/World.
- `video-camera` glyph still unverified in the bundled Phosphor.ttf (RECORD
  stands in).
